## 已部署改动

1. `Repair-WordBlankPages` 只在文档未修改时复用本轮页面映射。正常无改动路径从三次全书映射减为一次；删除分页符、调整分节、末段格式修复或恢复之后仍刷新。保存和字段处理后的主流程完整 Word 审计及最终 PDF 全书验收保留。
2. `Get-CoverLastLineUnitCount` 对确认同页的标题从尾部按需读取末行，不再查询整段所有字符的行号。跨页、不可用或异常行号回退原完整算法；两行上限、第二行一至两词的判断和 26→14 字号选择不变。
3. `Get-FrontParagraphs` 单次获取段落数量，使用列表收集结果，减少 COM 调用和数组复制。
4. 封面排版只接受同页、连续的标题与说明书标签；表格、目录及中间出现正文的文字块受到保护。
5. 报告增加 `cover_typography_workload` 与 `word_blank_page_audit_count`。后者只计空白页修复函数内部映射次数，不代表整个流程所有 Word 审计次数。`process_batch.VERSION` 和 Word 报告版本升为 `3.4.27`，使旧审计缓存失效。
