# 已冻结契约：代码中文注释清理

状态：Confirmed  
证据：`scripts/code_comment_cleaner.py`、`scripts/unified_workflow.py`、`tests/test_code_comment_cleaner.py`、`README.md`。

## 范围

- 仅处理成对存在的 `*代码.docx` 与同名 PDF。
- TXT、说明 DOCX/PDF 只复制，不读取或修改其内容。
- 原 RAR 不移动、不修改；结果写入时间戳目录；本阶段不重新压缩。

## 行为

- 默认先预览，确认后执行；规则稳定后可显式跳过预览。
- 删除含汉字的真实注释，覆盖 `//`、`/*…*/`、`/**…*/`、Python `#`、HTML `<!--…-->`、SQL `--`。
- 保留英文注释、字符串、模板字符串、正则、HTML 页面文字、CSS 颜色/选择器/URL、Python 三引号内容和运算符。
- 无法可靠判断的内容保留并列入报告。
- 正式清理后从 DOCX 重新生成 PDF；新 PDF 验证有效后才替换输出副本中的旧 PDF。
- 单项目失败不阻断其他项目，但批次必须返回部分失败状态并记录原因。

## 冻结边界

用户已确认这一期无需继续修改和验证。下一期不得顺手重构本模块，也不得把重新跑代码阶段验证作为开工前置条件。
